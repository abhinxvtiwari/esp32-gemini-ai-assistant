# ESP32 Gemini AI Assistant

An AI-integrated embedded system built using ESP32, microphone input, and Gemini API to process voice commands and trigger hardware responses.

## Features
- Voice-based interaction
- Gemini API integration
- Real-time hardware response
- ESP32-based embedded system
- AIoT experimentation

## Technologies Used
- ESP32
- Arduino IDE
- Gemini API
- Embedded C/C++
- IoT Concepts

## Project Workflow
Voice Input → Gemini API → ESP32 Processing → LED/Hardware Response

## What I Learned
- API integration with embedded hardware
- ESP32 programming
- Hardware interfacing
- Debugging and testing
- AI + IoT workflow concepts
